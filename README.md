  <h3>⚠️ METRIC SYNCHRONIZATION & ACCURACY LOGS</h3>
  <ul>
    <li><b>Why is the data displaying C++ and TypeScript instead of my current work?</b> The language card calculates percentages across your <i>entire public history</i>. If you have large historical or cloned repositories containing TypeScript, they will skew your breakdown until your new, active Java and Python repositories outpace them in overall code volume.</li>
    <li><b>GitHub Cache Delay:</b> GitHub caches profile imagery aggressively. New commits, pull requests, or code contributions can take up to <b>12–24 hours</b> to populate and refresh through the API endpoints onto your profile surface.</li>
    <li><b>Token Validation:</b> Because we are hiding the star-weighted grade metric (<code>hide_rank=true</code>), the interface remains streamlined. If your numbers completely freeze, verify that your <code>PAT_1</code> classic token hasn't expired or been revoked inside your Vercel project environment settings.</li>
